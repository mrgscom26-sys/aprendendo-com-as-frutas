# Audio Assets

Este diretório está reservado para arquivos de áudio estáticos opcionais (.mp3 / .ogg).
A aplicação "Aprendendo com as Frutas" opera nativamente com a Web Speech API (`window.speechSynthesis`) para a locução da voz didática feminina em português brasileiro e com a Web Audio API (`AudioEngine`) para síntese de efeitos sonoros em tempo real por osciladores (acordes de sucesso, toques encorajadores e fanfarra triunfal), garantindo funcionamento 100% autônomo, offline e leve.
